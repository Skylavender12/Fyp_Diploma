# [IMMENSUS JOURNEY]

Endless runner game built with Unity and C#, with an online leaderboard website and a story that unlocks the more you play. Developed as my Diploma Final Year Project (FYP).

## Features

- **Endless runner gameplay:** obstacles, increasing difficulty the longer you play.
- **Online leaderboard:** scores are submitted from the game to a website where players can compare rankings
- **Progressive story:** new story chapters are revealed as you play

## Project Structure

```
Assets/            Game scripts, scenes, art and audio
Packages/          Unity package dependencies
ProjectSettings/   Unity project configuration
```

## My Role

I designed and developed the game, designed the sprites and website as a solo project.

## What I Learned

- Connecting a Unity game to a web backend
- Designing a progression and story unlock system
